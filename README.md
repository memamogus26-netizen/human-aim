# Human Aim Assist (Meteor addon, Minecraft 1.21.11)

Build: JDK 21, then `./gradlew build` (jar in build/libs).
Or push to GitHub: the workflow builds it and publishes the jar under Releases ("Dev Build").

Versions live in gradle/libs.versions.toml. If a version "does not exist",
update `yarn`, `fabric-loader` and `loom` there to the latest 1.21.11 values from https://fabricmc.net/develop.
